# Cinelyo: AI Video Generator for Cinematic Content

Seedance 2.5 is now available on Cinelyo: a practical AI video workflow for creators.

[Cinelyo](https://cinelyo.com) is an AI-powered video generation platform that helps creators turn ideas, images, and reference materials into cinematic short-form videos.

With Cinelyo, users can describe a scene in natural language, upload visual references, choose a generation model, and create polished AI videos directly from the browser.

## Create Videos from Text, Images, and References

Cinelyo supports three main creation workflows:

### Text-to-Video

Describe a subject, environment, action, camera movement, lighting, and visual style using a simple text prompt. Cinelyo transforms the description into a short AI-generated video.

This is useful for:

- Creative concept exploration
- Film and commercial previsualization
- Social media video ideas
- Cinematic scene development
- Educational and explainer content

### Image-to-Video

Upload an image and bring it to life with motion. Cinelyo can animate product images, character designs, storyboard frames, architectural scenes, and other visual concepts.

The uploaded image provides a visual foundation, while the prompt controls the subject's movement, camera direction, lighting, and atmosphere.

### Multi-Reference Video Generation

Cinelyo allows creators to combine different types of reference materials in one generation workflow.

Users can provide:

- Up to 9 image references
- Up to 3 video references
- Up to 3 audio references

These materials can be used to control character identity, product appearance, camera motion, visual style, timing, rhythm, and sound direction.

## Seedance Video Models

Cinelyo provides several Seedance generation options for different creative needs:

- **Seedance 2.5** for longer continuous shots and extended video concepts
- **Seedance 2.0** for higher-resolution and final-quality output
- **Seedance 2.0 Fast** for rapid experimentation and creative iteration
- **Seedance 2.0 Mini** for lower-cost drafts and early direction testing

Users can choose the model, duration, resolution, aspect ratio, and other settings before generating a video.

## A Simple Creative Process

Creating a video with Cinelyo takes only a few steps:

1. Describe the shot or upload a visual reference.
2. Add images, videos, or audio when additional control is needed.
3. Select the model, duration, resolution, and aspect ratio.
4. Generate the video.
5. Review the result and refine the prompt for the next version.

This workflow allows creators to move quickly from an initial idea to a usable visual concept.
